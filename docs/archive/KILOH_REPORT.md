# KILOH Engineering Status Report — Specification

Generated by `scripts/kiloh-report.mjs` at the start and end of every work
session. Provides the Chief Architect with decision-ready operational
visibility — no code digging required.

## Sections

1. **Executive Summary** — what changed, completed, in progress, blocked, biggest risk (5–10 sentences).
2. **Repository Health** — branch, base, open PR, stack position, drift, conflicts, working tree, last build/deploy, CI.
3. **Project Health** — build, test, lint, TypeScript, coverage, perf regressions, security warnings.
4. **THINK Protocol Compliance** — T/H/I/N/K verified; violations highlighted.
5. **Active Objectives** — name, priority, owner, status, % complete, dependencies, blockers.
6. **Open Pull Requests** — number, title, branch, status, CI, review, merge readiness.
7. **Active Agents** — name, mission, task, heartbeat, files, state.
8. **Architecture Changes** — new/removed modules, API/DB/event changes, breaking changes.
9. **THINKBOX Status** — progress per subsystem (detection, deps, sandbox, graph, memory).
10. **Technical Debt** — TODOs, FIXMEs, disabled tests, `any`, duplicate/dead code, deprecated APIs, outdated packages.
11. **Dependency Health** — outdated, vulnerable, major updates, duplicates, unnecessary.
12. **Performance** — startup, build time, bundle size, memory, CPU, API latency.
13. **Knowledge Base** — ADRs, snippets, journal entries, decisions, protocol updates.
14. **Risks** — top five with severity, impact, probability, mitigation.
15. **Recommended Next Objective** — one recommendation with reason, effort, risk, impact.

## Closing Questions

Every report ends with three forcing questions:

1. What should we stop doing?
2. What should we start doing?
3. What is the single highest-leverage next task?

## System Readiness Score

A single 0–100 score computed from weighted subscores:

- Repository health (20)
- CI status (15)
- Test health (15)
- THINK protocol compliance (15)
- Architecture health (15)
- Security posture (10)
- Technical debt load (10)

Score bands: 90+ EXCELLENT, 75–89 GOOD, 60–74 FAIR, <60 AT RISK.
