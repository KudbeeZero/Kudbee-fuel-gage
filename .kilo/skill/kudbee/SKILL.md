# Kudbee Architecture

## Frontend
- **SPA tabs:** 5 — OVERVIEW, WORKSPACE, THINKBOX, TERMINAL, STUDIO
- **Framework:** React 19 + Vite + Tailwind 4 + React Router 8 + zustand
- **Build entry:** `index.html` only

## Backend
- **Entrypoint:** `services/ingestion/server.js`
- **THINK Protocol:** 4-pillar decentralized reasoning network
- **Pipeline:** 7-layer middleware chain
