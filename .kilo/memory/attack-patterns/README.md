# Attack Pattern Registry

This directory stores learned attack patterns and auto-generated countermeasures.
Each file represents a unique attack signature discovered by the Disruption Layer.

## Structure

```
.kilo/memory/attack-patterns/
├── prompt_injection/
│   ├── 2026-07-30_ignore-previous.json
│   └── 2026-07-30_system-override.json
├── tool_abuse/
│   └── 2026-07-30_execute-shell.json
├── countermeasures/
│   └── generated-zod-schemas.ts
└── registry.json
```

## Pattern Schema

```json
{
  "id": "pattern-{timestamp}-{hash}",
  "attackType": "prompt_injection",
  "pattern": "ignore previous instructions",
  "regex": "/ignore\\s+previous\\s+instructions/i",
  "severity": "high",
  "firstSeen": "2026-07-30T18:00:00Z",
  "lastSeen": "2026-07-30T18:00:00Z",
  "occurrences": 42,
  "countermeasure": {
    "action": "sanitize",
    "efficacy": 0.95
  }
}
```

## Auto-Generation

Patterns are auto-generated by:
1. `scripts/generate-countermeasures.mjs` (runs on-demand or via CI)
2. Real-time learning from `kudbee:disruption:attacks` Redis stream
3. Manual red-team exercises
